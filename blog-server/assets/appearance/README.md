# 每日主题素材

这里保存项目所有者提供的壁纸素材优化副本，原始文件来自其桌面素材目录，壁纸文件标注来源为彼岸图网。

- 19 张去重 JPEG，合计约 3 MB；最长边 1920 像素。
- 文件名是优化后内容 SHA-256 的前 20 位，用于稳定 URL 与缓存校验。
- `catalog.json` 是唯一公开白名单；不包含原文件名与本机路径。
- 由 [prepare-daily-artwork.py](../../../scripts/prepare-daily-artwork.py) 生成。
- 使用与维护说明见 [每日配色](../../../docs/daily-appearance.md)。
