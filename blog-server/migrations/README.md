# 数据库结构脚本

此目录只保存应用运行所需的建表/迁移 SQL，不包含真实数据、密码或个人笔记。数据库手动维护，不使用 GORM AutoMigrate。

新建空库只执行 `20260913_initial_schema.sql`，它已包含此前增量。已有数据库先备份，核对实际表结构和已应用变更，再执行尚未应用的增量；不能按文件列表全部重跑。`category_schema.sql` 是分类表的独立历史脚本，完整初始化后不重复执行。

历史点赞切换使用 `20260908_add_comment_like.sql` 创建关系表。若旧系统存在 Redis Bitmap 点赞数据，应先暂停点赞/撤回写入并备份 MySQL 和 Bitmap，再核实用户/评论有效性，迁移关系到 comment_like；回填只增加关系，不再次增加聚合计数。旧写入和回填不能并发，新代码接管前检查关系数与评论计数。没有历史点赞的新空库无需此回填。

执行前确认目标数据库名和环境。测试通过不代表目标数据库已迁移；不兼容的数据变更不能仅靠回退代码恢复。
